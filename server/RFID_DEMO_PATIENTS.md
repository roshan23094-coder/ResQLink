# ResQLink demo RFID patient profiles

The backend seeds four fictional patient profiles for demonstration. These are not real people or medical records.

| Patient ID | RFID UID | Demo profile |
|---|---|---|
| P1001 | F1 49 72 66 | Ramesh Kumar, 58; illustrative previous heart attack history and cardiology follow-up |
| P1002 | 1A 3A 51 32 | Lakshmi Devi, 46; routine diabetes follow-up |
| P1003 | FD 98 B4 E3 | Arjun Shetty, 34; asthma follow-up |
| P1004 | 87 C8 FA 2E | Priya Nair, 63; hypertension follow-up |

Unrecognized RFID cards are not registered or assigned. Patients without one of these registered cards use manual registration and receive no RFID UID. All profile details are illustrative placeholders; replace them with consented test data before any real use.
